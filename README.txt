NextGenInnov8 Digital Business Cards

Static Cloudflare Pages site.
- /card/ employee directory
- /card/<employee-slug>/ individual card
- /card/<employee-slug>.vcf vCard download

Deploy the contents of this folder to the Cloudflare Pages project connected to the GitHub repository.
All pages send noindex/nofollow/noarchive signals. This discourages search indexing but does not make the URLs private.

Before production launch, confirm that the displayed employee contact details and profile photos are approved for public sharing.
